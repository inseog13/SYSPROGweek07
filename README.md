## 사용한 프롬프트

### 1. 메인 룰 템플릿
메인 룰:
1. 반드시 스킵 없이 하나하나 구체적으로 설명할 것(설명을 할 때 너무 난해한 경우에는 쉬운말로 풀어 써야됨, 지루하지 않도록 중간에 농담이나 재미있는 이야기도 섞을 것)
2. 잘못된 정보가 존재하는지 확인 하고, 존재한다면 공신력 있는 곳에서 다시 검색할 것(시간은 3분으로 제한하며, 그래도 발견이 안될 경우 정확한 정보를 찾지 못함을 알리며 다음 의견을 묻고, 수락 시 가장 비슷한 정보라도 알릴 것)
3. 시청각 자료 또는 실제로 사용되는 자료를 같이 사용하여 이해력을 돕도록 할 것(단, 토큰비용을 생각해서 가장 시청각 자료가 필요한 경우에만)
4. 사람이 이해하기 어려운 출력은 절대 하지 말 것

### 4. 구체적인 문제와 조건 제시
문제: 파이프로 왕복
<br>조건:
<br>1_pipe_basic.c 를 변형.
<br>./1_pipe "hello world" 부모가 보낸 문자열을 자식이 대문자로 바꿔 돌려준다(파이프 2개 필요).
<br>파이프는 단방향이라 왕복에는 두 개가 필요하다.
<br>각 프로세스가 쓰지 않는 끝을 닫아야 상대가 EOF 를 본다.

문제: dup2 로 명령 이어 붙이기
<br>조건:
<br>2_pipe_dup2.c 를 변형.
<br>./2_pipeline ls -l : wc -l (: 로 두 명령 구분) 앞 명령의 표준출력과 뒤 명령의 표준입력을 각각 dup2 로 바꿔치기한다.
<br>부모는 파이프 양쪽 다 닫아야 뒤 명령이 끝난다.

문제: FIFO 로 메시지 주고받기
<br>조건:
<br>3_fifo_read.c / 4_fifo_write.c 를 변형해 받는 쪽·보내는 쪽 한 쌍을 만든다.
<br>받는 쪽을 먼저 실행한다.
<br>open 은 상대가 반대쪽을 열 때까지 기다린다.
<br>끝나면 unlink 로 FIFO 를 지운다.
